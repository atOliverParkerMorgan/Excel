# FITExcel – Spreadsheet Processor

FITExcel is a spreadsheet processor developed as part of a course project at FIT CTU. It can manipulate cells, calculate values based on formulas, detect cyclic dependencies, and save/load the contents of a spreadsheet.

## Repository Contents

- **AST/**: Files for the abstract syntax tree.
- **CMakeLists.txt**: Configuration file for CMake.
- **CPos.cpp, CPos.h**: Implementation of table position handling.
- **CSpreadsheet.cpp, CSpreadsheet.h**: Implementation of the spreadsheet processor.
- **expression.h**: Definition of the Expression class for expression processing.
- **hash_pair.h**: Definition of a hash function for pairs of values.
- **README.md**: Information about the repository.
- **test.cpp**: Tests for the spreadsheet processor functions.
- **x86_64-linux-gnu/**: Files for a specific architecture.
